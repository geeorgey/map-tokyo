# 駅舎の細密化

2026-09-05。簡略形状だった駅舎を専用の `src/engine/station.js` に置き換えました。

- 軒・屋根・中央部・南北ドームの高さのバランスを、公式の外観説明図を参考に調整。
- レンガの色むら、交互の積み方、目地、表面の凹凸を生成した素材で表現。壁の大きさが変わってもレンガの寸法が揃うUVを使用。
- 三層の窓を増やし、石の縁取り、窓台、桟、アーチの立体形状を追加。
- 柱の石装飾、段になった軒、軒下の小さい装飾を追加。
- 単純な屋根を勾配が変わる形状にし、スレート、丸い屋根窓、煙突、雨樋、尖塔を追加。
- ドームを専用の曲面形状に変更し、屋根の継ぎ目、屋根窓、頂部、時計、入口庇を追加。
- 近距離で影が細かくなるよう調整し、ズームの最短距離を55から20に変更。
- 窓や部材はインスタンス描画で共有し、新しい素材は終了時に破棄。

ブラウザで接近視点の外観、屋根の小窓・ドーム・時計、夜の発光を確認。実行時のerror/warnログなし。細密化後の接近視点で約120fpsを観測。最終ビルド成功（Three.jsチャンクは約514KBで、500KB超のサイズ目安の警告あり）。

参考：[Tokyo Station City — 丸の内駅舎のみどころ](https://www.tokyostationcity.com/learning/station_building/)。外観を参考にしたオリジナルの形状であり、写真をそのまま貼ったモデルや実測に基づく完全な復元ではありません。
