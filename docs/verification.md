# 実装・検証メモ

2026-09-05。React + Vite + Three.jsによるリアルタイム3D描画。既存ゲームの素材を使わず、東京駅周辺の雰囲気を簡略化したオリジナルモデル。

## 画面の比較

画像生成ツールで作成した設計参考は `design-concept.png`、最終ブラウザ画面は `preview.png`。両方を `view_image` で開いて比較した。参考画像の方向性を反映したが、画像そのものの精密な立体再現・ピクセル単位の一致ではない。

| 比較点 | 確認・調整 |
| --- | --- |
| 情報構成 | 全画面の3Dビュー、左上タイトル、右上の時間帯、左下の視点、下部の走行操作を維持 |
| 文字 | 明朝体タイトルと小さい英文サブタイトル、ゴシック体の操作ボタンを実装 |
| パネル | 淡い半透明パネル、オリーブ色の選択状態、控えめな角丸を反映 |
| 色・光 | 灰青色の空、赤レンガ、青緑のビル、緑の樹木。白飛びを見て昼の光量と露出を修正 |
| 構図 | 初期視点を上げて手前の高層ビルによる駅舎の遮蔽を軽減。狭い画面では画角を広げる |
| 建築 | 駅舎の3層の窓、南北ドーム、屋根の小窓、後面の窓、ビルの低層部分を追加。ドーム窓が壁に埋まる問題を修正 |
| レスポンシブ | 狭い画面では視点を下部の横並びボタンへ変更し、全操作を画面内に配置 |
| 動き | 実際のカメラ旋回・列車運行・停止・速度変更を実装。動きを減らす設定では視点の補間移動を省略 |

意図的な相違：写真のような高密度テクスチャではなく、回転しても成立する手続き生成の3D形状。建物の高さ・配置・形、緑地の密度、縮尺、線路や運行は簡略化。初期視点では皇居側の緑地は画面外になるが、旋回や街全体の視点で見られる。

主要ボタン・タイトルの文言は設計参考と一致。追加文言は視点番号01〜04、右ドラッグの説明、操作方法ダイアログ、書き出しプレビューに限定。ゲームの経営・スコア・建設機能は追加していない。

## ブラウザ検証

Codex In-app BrowserをCUAで操作。Playwright別ブラウザへのフォールバックは未使用。

- 通常の表示幅：約660 × 856。最終スクリーンショットを保存。
- デスクトップ検証：1568 × 1004を指定したが、ブラウザの120%ズームによりCSS表示領域は1306 × 836。指定サイズの画像キャプチャには余白が入るため、最終保存画像は通常の表示幅を採用。コンセプトのネイティブ寸法との厳密なスクリーンショット一致は未確認。
- モバイル検証：CSS 390 × 843。横スクロールなし、表示ボタンの全境界が画面内に収まることを確認。実機の指操作は未検証。
- 4つの視点をクリックし、駅舎・ホーム・街全体を目視確認。
- ドラッグ・ホイール・全景リセットを実操作。
- 自動旋回でコンパス角度が51.6027度から52.2113度に変化することを確認。
- 昼・夕・夜を切り替えて空・光・窓の点灯を目視確認。
- 一時停止後の3D部分のスクリーンショットが、時間をあけてもSHA-256で一致。停止中の列車が静止することを確認し、その後再開。
- 速度ボタンで1倍から2倍への変更、ラベル表示、説明ダイアログ、Escapeで閉じる操作を確認。
- PNGプレビューは実画像として読み込み完了、1153 × 1498ピクセルのPNGとダウンロード用ファイル名を確認。IABでは自動ダウンロード完了イベントを確認できなかったため、画像を確認して保存できるプレビュー画面へ変更。端末のダウンロードフォルダへの保存完了は未確認。
- 手元の実行環境では説明パネルに約120fpsと表示。他の機種での性能は保証しない。
- 最終確認時、ブラウザのerror/warnログなし。
- `npm run build` 成功。JSを分割し、ビルドの大きなチャンク警告も解消。

一時的なブラウザサイズの指定は解除し、昼・東京駅全景・1倍速・走行中・自動旋回なし・ラベルなしで引き渡し。
