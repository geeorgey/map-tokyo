# 東京鉄道景

東京駅・丸の内・八重洲を眺める、ブラウザで動く3Dジオラマです。赤レンガ駅舎、南北ドーム、実際の線形に沿う線路、6編成の列車、ビル、車、街路樹を描画します。経営・建設・スコアなどのゲーム機能はありません。

## 正本と現在の実装

編集・履歴の正本は **https://github.com/geeorgey/map-tokyo** です。別のMacでもこのリポジトリから取得し、変更ごとにコミットします。公開先は https://train.lvnsk.jp/ 。公開中のソースコミットは `/release.json`、デプロイ後の検証記録は `docs/deployment-verification.json` で確認できます。

- 日本時間の日時表示、任意日時への移動、0.5〜300倍速、停止・再開、現在時刻への復帰。
- 公式時刻表に合わせた発車。平日・土休日・指定運転日と午前3時の運行日境界に対応。
- 昼・夕・夜、新幹線追従、約90秒の「光の移ろい」、車両詳細、PNG保存。
- **遅延・運休・実測位置は取得しません。** 入線・停車時間は演出、番線・車両は代表表示です。

3Dモデルを含む編集用ソースは `src/` に統合しています。`recovery/realtime-2026-09-06/` は別環境で作成した9月6日版の原本です。比較・復旧用に保持し、このディレクトリから本番へデプロイしないでください。経緯と各版の対応は [docs/release-history.md](docs/release-history.md) に記録しています。

## 起動

Node.js 24を推奨します（`.nvmrc`）。Cloudflare CLIを含めた最低条件は22.12以降です。

```sh
npm ci
npm run dev:worker
```

ブラウザで http://127.0.0.1:4180 を開きます。時計・同梱データ・時刻表取得APIを含む確認にはこちらを使います。`npm run dev` と `起動.command` はViteの画面開発用で、別月の時刻表取得APIは提供しません。

## 操作

- 「メニューを隠す / 表示」で時計や設定をまとめて切り替え。スマホは景色を広く見られるよう、最初は非表示です。散策中は移動パッドを残します。

- 左ドラッグ：回転
- 右ドラッグ：平行移動
- ホイール：拡大・縮小
- タッチ：指1本で回転、指2本で移動・ピンチ
- 左下の5ボタン：全景、駅舎、ホーム、街全体、新幹線へ移動
- 昼・夕・夜：光、空、窓の点灯を変更
- 下部：列車・時計の一時停止、0.5〜300倍速、自動旋回、建物名の表示
- ホーム屋根を隠す：屋根を非表示にしてホーム端と線路を確認
- カメラ：UIを除いた現在の風景をPNG保存
- Space：停止・再開、0：全景に戻る

## 構成

- `src/engine/geometry.js`：共通のインスタンス描画、車両形状
- `src/engine/world.js`：街・鉄道の組み立て
- `src/engine/urban.js`：実地図の道路・建物・水辺、壁面描画
- `src/engine/railway.js`：地図の線路形状と接続に沿った列車経路
- `src/engine/platforms.js`：10面のホーム輪郭、屋根、点字ブロック、柱
- `src/engine/rail-layout.js`：中央線の高さと勾配の共有計算
- `src/data/tokyo-platforms.json`：出典付きホーム輪郭・線路の軌間データ
- `src/data/tokyo-map.json`：出典付きのローカル地図データ
- `scripts/prepare-map.py`：OSMデータの座標変換・形状生成
- `src/engine/station.js`：駅舎の詳細形状、レンガ・スレート素材、アーチ窓、ドーム
- `src/engine/viewer.js`：カメラ、光、列車・車のアニメーション
- `src/App.jsx`：画面操作
- `src/style.css`：デスクトップ・モバイル表示

大量の窓・枕木・樹木をInstancedMeshでまとめて描画。生成シードを固定し、再読み込み後も同じ街になります。外部APIキーや地図APIは不要です。タイトル用WebフォントはGoogle Fontsから読み込み、未接続時は端末の明朝体にフォールバックします。

## モデルについて

既存ゲームの素材を使わず、一から作ったオリジナルの描画です。東京駅を中心とする約1.46 × 1.71 kmの範囲で、道路中心線・建物輪郭・中庭・水辺をOpenStreetMapから生成しています。1,427個の建物ボリューム（棟数ではなく低層部・高層部を含む形状数）、729区間の道路、195区間の線路を収録しています。

建物の高さは登録値・階数を優先し、未登録分を推定しています。上部形状が未登録の高層棟は内側に縮めた形で補完。道路幅、緑化、外壁、駅舎の細部、鉄道の高さ・ホーム・運行も簡略化または推定です。データの未登録・更新遅れがあり、実測による現況の完全な復元ではありません。

地図データ：© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)、ODbL 1.0。画面とPNG書き出しに帰属表記を表示します。[変更と検証](docs/map-realism.md) / [データと再生成](DATA-LICENSE.md)。

駅舎の参考：[Tokyo Station City — 丸の内駅舎のみどころ](https://www.tokyostationcity.com/learning/station_building/)

描画：[Three.js](https://threejs.org/) / 操作：[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)

## 駅舎の細密化

丸の内駅舎の参考資料に合わせて、軒・屋根・ドームの高さの比率を調整。目地と色むらのあるレンガ、スレート屋根、立体のアーチ窓、窓枠と桟、柱の石装飾、軒下の持ち送り、ドームのリブ・時計、屋根窓、尖塔、煙突、雨樋、入口庇を追加しています。レンガ・屋根素材はプログラムで生成し、外部の写真素材を貼り付けていません。「丸の内駅舎」で詳細表示に移動できます。最短ズーム距離も短くしました。外観を参考にしたモデルであり、実測に基づく忠実な復元ではありません。

## ホームと線路の整合

ホームはOSMの10面のポリゴンから生成します。長さ・幅・曲線・端部を一律の箱にせず、ホームの輪郭に沿って床・点字ブロック・屋根・柱を配置します。地図の線路とホームの測位差は車両との離隔を確保する方向に補正し、補正前の輪郭もデータ内に保持します。

中央線1・2番線は他のホームより高く配置し、列車にも線路と同じ高さ・勾配を適用しています。高低差6.5 mと北側の勾配は概算で、測量値ではありません。屋根・柱もホーム輪郭からの生成です。[JR東日本の東京駅構内図](https://www.jreast.co.jp/estation/stations/1039.html)で番線構成を照合しています。

車体は前後の台車位置から向きと位置を算出し、線路の折れ点で車端が飛び出す問題を修正しました。通常軌道と新幹線の軌間は地図の登録値を使用し、車体幅も調整しています。

## 新幹線

18番線にN700系風の白地・青帯の16両編成、20番線にE7系風の青い屋根・銅色の帯の12両編成を描画します。車両形式の振り分けを番線・軌間に基づいて行い、在来線の経路には配置しません。両端の流線形の先頭車、窓、扉、台車、パンタグラフ、進行方向に合わせた前照灯・尾灯を追加しました。

新幹線は線路に沿って減速入線し、20秒停車して来た方向に折り返します。実際のダイヤや当日の番線指定を再現するものではありません。「新幹線」視点を選ぶと屋根を隠し、2編成の入線・停車シーンから再開します。一時停止と速度変更は既存ボタンで操作できます。

N700系風は先頭車27.35 m・中間車25 m、全長404.7 m。E7系風は先頭車26 m・中間車25 m、全長302 mの簡略化モデルです。台車位置に基づいて車体を曲線へ追従させています。

参考：[JR東海 N700系・N700A](https://railway.jr-central.co.jp/train/shinkansen/detail_01_01/index.html) / [JR東日本 E7系](https://www.jreast.co.jp/train/shinkan/e7.html)

## 新幹線の車体詳細と色

「新幹線の車両詳細」から、街で走行するものと同じモデルを拡大・回転できます。N700系とE7系の切り替え、先頭部・側面・正面の視点を備えています。詳細表示中は街の列車走行を止め、閉じると元の再生状態に戻ります。

先頭形状は形式ごとの曲面に分け、N700系の扁平な鼻先とE7系のワンモーションラインを再構成しました。車体の塗装は頂点カラーの補間を廃止して境界を明確化。運転席ガラス、ワイパー、灯具、曲面に沿った角丸窓、扉、台車の車輪、連結部、床下機器も追加・修正しています。N700系のパンタグラフは5・12号車に配置します。実測CADではなく、細部の断面・窓配置・機器は資料からの近似です。

| 形式 | 車体 | 青 | 銅色 |
| --- | --- | --- | --- |
| N700系 | `#F4F5F2` | `#154A85` | — |
| E7系 | `#EEECE5` | `#285F98` | `#B88770` |

数値はsRGBの**表示用近似色**です。N700系はメーカーの実車写真、E7系は鉄道会社のエクステリア資料を参考に目視調整しています。公表された塗料規格、測色値、公式HEXとの一致は確認できていません。公式塗装コードとして扱わないでください。E7系の公式な色名は「空色」「アイボリーホワイト」「銅色（カッパー）」です。3D上の見え方には照明・反射・トーンマッピングが加わり、画面の色票は設定したsRGB値を直接表示します。

出典：[日本車輌 N700系（寸法・実車写真・編成図）](https://www.n-sharyo.co.jp/business/tetsudo/pages/jrcn700.htm) / [JR東日本・JR西日本 E7/W7系共同発表資料（外観・色名）](https://www.westjr.co.jp/press/article/items/120904_00_hokuriku.pdf)。資料の画像自体はアプリに同梱していません。

モデル実装：`src/engine/train-model.js`。色は同ファイルの`bulletTypes`で一元管理し、街の車両・詳細表示・色票が共通の値を参照します。

## 架線設備と入線・発車

線路上にはトロリ線・吊架線・ハンガーを追加し、195区間の地図線形と中央線の高低差に追従させています。横棒だけの架線柱は73基のトラス式支持設備へ置き換え、柱が隣接線路の車両通過範囲に入らない位置で生成しています。新幹線のパンタグラフとトロリ線は共通の高さを参照します。支柱位置・形式・線路面上5 mの接触高さは描画用の近似であり、東京駅の設備を実測復元したものではありません。

9月5日の旧デモ運行では、在来線は加速・定速・減速を経てホーム中央で12秒停車し、再び加速します（現在の公開版は時刻表運行です）。速度は時刻から計算し、フレームレートや速度倍率によって停止位置がずれないようにしています。編成全体が経路内に収まる範囲で走行し、経路端で5秒の非表示期間を挟んで再出現します。実際の運行ダイヤや信号制御は対象外です。

「ホームと列車」は設備や動きが見やすい近めの視点に変更しました。ホーム屋根を隠すと架線と列車の位置関係を確認できます。

検証：`npm test`（架線の線形・高さ、支柱の車両離隔、パンタグラフの接触高さ、加減速・停止の連続性、編成の経路内収容） / `npm run build`。

## 2026-09-06：新幹線を追う

「新幹線を追う」でN700系の先頭車付近へ移動し、入線・停車・折り返しを追従して眺められます。開始時は入線シーンに合わせ、ホーム屋根を自動で隠します。追従中も回転・ズーム・パンが使え、列車の移動に対する視点の位置関係を保ちます。一時停止・速度変更にも対応しています。

同じボタンで追従を解除すると現在の場所に視点を残します。通常の視点ボタン、コンパス、0キーでも追従を終了できます。追従対象は折り返し時も同じ車両に固定し、編成の反対端へカメラが飛ばないようにしています。

### 2026-09-08：光の移ろい

時間帯ボタンの下に「光の移ろい」を追加。約90秒で昼→夕→夜→昼を巡り、空・霧・光源・影・建物の明かりを連続的に変化させます。もう一度押すと途中の明るさで停止し、再開するとその位置から続きます。「昼」「夕」「夜」を選ぶと自動巡回を解除し、約1.8秒でその時間帯へ移ります。動きを減らす設定では手動切り替えは即時です。

列車の一時停止・速度、カメラ追従とは独立しています。実際の時刻・太陽位置を再現する機能ではなく、既存の照明プリセットをつないだ鑑賞用の演出です。


## 公式時刻表と公開手順

同梱時刻表はJR東日本の2026年9月号です。7路線・方向と運転日限定列車330件の運行日を取得。祝日は内閣府データを使います。別月は既存Workerの `/api/station`、`/api/calendars`、`/api/holidays` で取得し、未掲載・不完全なデータでは列車を表示しません。出典と提供元の利用条件は [復旧版の出典案内](recovery/realtime-2026-09-06/THIRD-PARTY-NOTICES.md) を参照してください。

```sh
npm run timetable -- 2026-09 --fresh
npm test
npm run build
npx wrangler whoami
npm run deploy:check
# 画面確認後にコミット・GitHubのデフォルトブランチへ統合してpush
npm run deploy
```

`npm run deploy` は未コミット変更、正本以外のorigin、GitHubデフォルトブランチと異なるコミットからの公開を拒否します。ビルドにコミットSHAを埋め込み、公開後に画面・API・SHAの一致を確認します。

## 2026-09-11：自由散策

「自由に歩く」で地上の目線に切り替わります。WASD・矢印キー、または画面の方向ボタンを押し続けて移動し、景色をドラッグ／スワイプしてその場で見回せます。視点は駅の中央に固定されません。「東京駅の正面へ戻る」で開始位置、「上から眺める」で従来の全景へ戻ります。

今回は建物の外の散策です。建物輪郭・水面・駅舎とホーム周辺を進入制限に使用します。実地の歩道ナビゲーションや駅舎内の再現ではありません。移動は時計の速度や一時停止と独立し、画面外に移る・ダイアログを開くと入力を解除します。
